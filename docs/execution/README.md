# PRD 전체 실행 작업표

통합 기준: **codex/workspace-redesign**. 제품 main 반영은 통합 검증 뒤 별도 최종 PR로 수행한다. 기준 작업 스냅샷 0e4ef4e는 기존 미커밋 보존이며 완료 승인 아니다.

[항목 원장](prd-items.json)은 PRD의 필수 요구·인수 기준과 위젯 TODO를 한 항목씩 기록한다. PRD의 명시적 후속 범위는 deferred로 유지한다. 구현됐더라도 인수 근거가 없으면 완료 처리하지 않는다.

각 PR 절차: 기준 브랜치 최신화 → 기능 브랜치 → 구현 → 의미 있는 검증 → PR(base=기준 브랜치) → 코드 리뷰 및 지적 수정 → 검증 근거·리뷰 문서 연결 → merge → 다음 작업. 자체 리뷰와 외부 자동 리뷰는 명확히 구분한다. 리뷰 요청만으로 리뷰 완료로 표시하지 않는다.

실메일·DNS·외부 채널 등 환경이 필요한 검증은 코드 완료와 별개로 미실행 근거를 남기며 전부 통과로 표시하지 않는다. 테스트는 격리 로컬 DB 사용. 실제 고객 데이터는 변경하지 않는다.
