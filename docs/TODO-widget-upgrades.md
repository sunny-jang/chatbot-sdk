# 위젯 개선 할 일 (뷰랩 병의원 챗봇 SDK에서 가져올 것)

작성: 2026-10-19 · 대상: `public/chatbot-widget.js`(실제 위젯), `packages/chatbot-sdk`(로더), 관련 API

뷰랩 병의원 챗봇 SDK(`@beaulab/hospital-chatbot-sdk`)를 채널톡처럼 개편하며 만든 기능 중, 이 위젯에 없거나 일부만 있는 것을 우선순위대로 정리했다. 뷰랩 쪽 코드는 Shadow DOM 위의 바닐라 TS라 구조가 비슷해 대부분 옮겨 쓸 수 있다.

## P0 — 보안 (먼저)

### 1. 위젯 제목·로고·색상 주입 막기
- **문제**: `chatbot-widget.js:220`이 `widget_title`과 `logo`를 이스케이프 없이 `innerHTML` 템플릿에 넣는다. `widget_color`도 CSS 문자열에 그대로 들어간다. `app/api/bots/[id]/route.ts`는 이 값을 검증하지 않고 저장한다. → 테넌트 관리자(또는 탈취된 계정) 입력이 **고객 사이트에 스크립트·CSS로 주입**된다(stored XSS).
- **할 일**
  - [ ] 위젯: 헤더를 `createElement` + `textContent`로 만들기. 로고는 `img.src`에 `https:`·`http:`·`data:image/(png|jpeg|webp|gif)`만 허용하고 나머지는 기본 마크.
  - [ ] 위젯: 색상은 `#RGB`/`#RRGGBB`만 받고 아니면 기본색.
  - [ ] API(`app/api/bots/[id]/route.ts`): 제목 길이·제어문자, 색상 형식, 로고 data URL 형식·크기를 저장 전에 검증.
  - [ ] `/api/widget/[botId]` 응답도 같은 규칙으로 한 번 더 걸러 보내기(기존 저장값 대비).
- **완료 기준**: 제목에 `<img src=x onerror=alert(1)>`, 색상에 `red;}body{display:none`, 로고에 `javascript:`를 넣어도 고객 페이지에서 실행·적용되지 않음.
- **크기**: 작음

### 2. Shadow DOM으로 격리
- **문제**: 위젯 DOM·스타일이 고객 페이지에 그대로 섞여 사이트 CSS(예: `* { … }`, `button { … }`)가 위젯을 깨거나, 위젯 스타일이 사이트에 새어 나갈 수 있다.
- **할 일**
  - [ ] 루트 `div`에 `attachShadow({ mode: "open" })`, 스타일을 `<head>` 대신 shadow root 안 `<style>`로.
  - [ ] `document.getElementById` 등 문서 기준 조회를 shadow root 기준으로 바꾸기(포커스 확인은 `shadowRoot.activeElement`).
  - [ ] 위젯 미리보기(`app/components/WidgetPreview.tsx`)·SDK `destroy()`가 그대로 동작하는지 확인.
- **완료 기준**: 고객 페이지에 공격적인 전역 CSS를 넣어도 위젯 모양이 그대로, 위젯 스타일이 페이지에 영향 없음.
- **크기**: 중간
- **참고**: 뷰랩 SDK `chatbot.ts`(mount)·`styles.ts`

## P1 — 체감이 큰 것 (코드 거의 그대로 옮김)

### 3. 안 읽음 알림
- **문제**: 상담원 연결 중 패널을 닫아 두면 상담원 답장이 와도 알 방법이 없다.
- **할 일**
  - [ ] DB: 상담 세션별 방문자 읽음 위치(`chat_sessions.visitor_read_at` 또는 마지막 읽은 메시지 ID) 추가.
  - [ ] API: 안 읽은 상담원 메시지 수 조회, 읽음 기록(`POST …/read`).
  - [ ] 위젯: 닫혀 있을 때도 폴링을 이어 가되 탭이 숨겨지면 멈춤(복귀 때 즉시 한 번). 런처에 빨간 점 + `aria-label "안 읽은 메시지 N개"`.
  - [ ] 위젯: 패널이 열려 있고 대화가 보일 때만 읽음 기록. 열면 안 읽은 진행 중 상담이면 그 대화로 바로.
- **완료 기준**: 패널을 닫은 뒤 상담원이 답하면 수 초 안에 점이 뜨고, 열어서 보면 사라짐. 숨긴 탭에서는 요청 0.
- **크기**: 중간
- **참고**: 뷰랩 SDK `inbox.ts`(refreshUnread·maybeMarkRead·숨긴 탭·늦은 응답 무시), 백엔드 `hospital_chatbot_consultation_hospital_reads`

### 4. 접근성 마무리
- [ ] 메시지 영역 `role="log"` + `aria-live="polite"`.
- [ ] 패널 Esc로 닫기, 닫을 때 FAB로 포커스 복귀.
- [ ] 다시 그려도 포커스 유지(상담원 연결 바·버튼 교체 시).
- **크기**: 작음 · **참고**: 뷰랩 SDK `chrome.ts`(focusKey), `views.ts`

### 5. 채널 프로필·운영시간
- [ ] 헤더 아래 응답 문구(운영시간 중/외 다르게, 관리자 입력·기본값). 위젯 설정 API에 필드 추가.
- [ ] 운영시간을 시간 외에만이 아니라 늘 접힘 바로(예: "운영시간 · 평일 09:30~17:30"), 펼치면 요일별·점심·휴일.
- **크기**: 작음~중간 · **참고**: 뷰랩 SDK `chrome.ts`·`schedule.ts`(요일 묶음 평일·주말·매일)·`operating-hours.ts`

### 6. 링크 버튼·자동 링크
- [ ] 답변(특히 Q&A봇) 아래 링크 버튼 최대 3개(http·https만, 새 탭). 관리자 Q&A 편집에 입력칸.

- **크기**: 작음 · **참고**: 뷰랩 SDK `rich-text.ts`(autolink), `views.ts`(link buttons)
