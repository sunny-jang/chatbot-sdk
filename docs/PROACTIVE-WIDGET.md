# 먼저 말 걸기: 초기 구현

챗봇 설정의 **먼저 말 걸기**에서 사용 여부, 문구, 최소 활성 체류 시간(5~300초)을 저장합니다. 기본은 끄기입니다.

## 동작

- 켠 경우에만 페이지 방문·SPA 경로 변경·탭이 보이고 활성화된 시간·링크/버튼 클릭 종류·200px 이상 스크롤을 감지합니다. 폼 내부 클릭과 입력값은 수집하지 않습니다.
- 페이지 경로에서 쿼리와 fragment를 제외하고 긴 숫자·UUID를 치환합니다. 버튼 원문 대신 가격/문의/서비스/기타 이동 분류만 저장합니다.
- 현재 탭의 sessionStorage에 최근 12개 이벤트를 저장합니다. 마지막 갱신 후 30분이면 새 방문으로 취급합니다. 서버나 AI 제공자에는 행동 데이터를 전송하지 않습니다.
- 보이는 탭의 체류 시간이 설정값에 도달하면 설정 문구의 말풍선을 표시합니다. 클릭이나 스크롤 없이도 표시합니다.
- 말풍선을 눌러야 채팅창이 열립니다. 한 방문에 한 번만 제안합니다. 직접 위젯을 열거나 상담원 연결이 진행 중인 방문에서는 제안하지 않습니다. 과거 챗봇 대화 기록 자체는 새 방문의 제안을 막지 않습니다.
- 설정 변경은 설치된 페이지 새로고침 후 적용됩니다. 끄면 행동 수집을 시작하지 않고 해당 탭의 행동 상태를 지웁니다.
- 세션 저장소가 막힌 브라우저에서는 현재 페이지 안에서만 반복 방지를 보장합니다.

챗봇 대화 세션도 현재 탭의 sessionStorage에 보관합니다. 새 탭에서는 새 대화 세션으로 시작하며, 기존 localStorage의 세션은 복원하지 않습니다. 기존 DB 기록은 삭제하지 않습니다.

## 범위

기본 인사 모드는 자동 수집 + 규칙 기반 표시입니다. AI 모드의 별도 동작은 아래 항목을 참고하세요. 영구 원본 행동 로그는 저장하지 않습니다. 화면에 보였다는 이유로 읽었다고 단정하지 않습니다. iframe으로 보여주는 다른 도메인 안의 행동은 수집하지 않습니다.

## 검증

`npx tsx --test tests/proactive.test.ts`

기본 끄기, 설정 보정, 개인정보를 포함한 버튼 원문 미저장, 비활성 탭 제외, 지연 조건, 중복 방지, SPA 경로 수집, 최근 이벤트 제한, 수집 종료를 검증합니다.

실제 사이트에서는 해당 챗봇에서 기능을 켜고 저장한 뒤 새 탭에서 홈페이지를 엽니다. 채팅을 열지 않은 상태에서 메뉴를 클릭하거나 스크롤하고 설정 시간만큼 활성 탭에 머뭅니다. 말풍선을 닫고 페이지를 이동해도 다시 나오지 않아야 합니다.


## 상황별 AI 제안 (2026-10-15)

- 기존 기본 인사는 유지하고 설정에서 AI 모드를 별도로 켭니다. 설치 사이트 origin과 봇별 월 평가 한도(기본 200회)를 지정합니다. 별도의 유료 플랜이나 과금 가격은 새로 만들지 않았습니다.
- 위젯이 공개 설명의 제목·주변 내용을 자동 구간으로 구성하고, IntersectionObserver로 노출과 스크롤 중에도 누적되는 체류를 관찰합니다. 최소 방문 30초, 관심 구간 5초부터 후보를 평가합니다. 같은 탭에서 최대 6개 관심 구간을 참고합니다.
- 후보의 제목·최대 200자 설명·노출 시간 구간을 서버에 보내며 입력값·연락처·전체 DOM·화면 캡처는 전송하지 않습니다. 로그인·결제·계정·폼 영역과 사용자 지정 경로는 제외합니다.
- 관련 등록 문서와 Q&A를 검색해 근거가 있는 경우에만 상담형 질문을 생성합니다. 현재 검색은 짧은 문서 구간의 키워드와 부분 문자열 점수 기반이며, 구간-자료 연결 정확도는 고객사 자료 구성에 영향을 받습니다.
- 고객사에 설정된 OpenAI/Gemini 모델·키를 사용합니다. OpenAI는 구조화된 JSON Schema 출력으로 문구와 근거를 검증합니다. 최대 모델 대기 4초입니다. 키 없음·모델 오류·월 한도에서는 기본 인사로 대체하고 자료가 없거나 제안이 부적절하면 생략합니다.
- 방문당 최대 2회 평가·1회 노출, 평가 간 60초, 재시도와 동시 요청은 중복 예약 방지. 평가와 사용 토큰은 대화 세션 차감과 별도로 기록합니다. 월 한도는 현재 봇 단위이며 파트너 합산 과금은 도입하지 않았습니다.
- 첫 질문을 누르면 채팅에 동일한 질문을 이어서 표시합니다. 고객의 실제 답변부터 기존 채팅 이용량을 적용하고, 서버가 검증한 제안과 근거로 상담을 이어갑니다. 클릭 자체를 고객의 관심 확인 발언으로 기록하지 않습니다.
- 분석 중 관심 구간·페이지가 바뀌면 오래된 제안은 버립니다. 표시 후 다른 구간으로 이동하면 제거하고 다시 노출하지 않습니다.
- 봇 테스트 화면의 **상황별 AI 제안 테스트**에서 새 테스트 방문을 생성하고 감지 구간·시간·표시/생략 이유·평가 사용량을 확인할 수 있습니다. 만료되는 서명 토큰으로 관리자 테스트만 등록 origin 검사에서 예외 처리합니다. 테스트에도 실제 모델 비용과 평가 한도가 적용됩니다.
- 제안 평가 메타데이터는 30일 후 기존 cron 정리 작업으로 삭제합니다. 원본 방문 행동 로그는 서버에 저장하지 않습니다.

### 검증 명령

```sh
npx tsx --test tests/proactive.test.ts tests/proactive-ai.test.ts
```

실제 모델·DB 검증은 명시적으로 켜야 실행됩니다. 아이디얼 테크 봇에 테스트 평가 메타데이터를 남기고 실제 모델 비용이 발생합니다.

```sh

```
