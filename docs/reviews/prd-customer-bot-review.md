# PRD 실행 03 — 고객사 관리자 챗봇 작업 공간 작성자 리뷰

## 범위와 권한

- 고객사 관리자/소유자의 자기 고객사 봇 목록, 응대 지침·인사·로고·시간 설정, 문서/Q&A/폴더 CRUD, 문서 파일·XLSX/CSV 가져오기, URL 검토·승인 반영, 설치 코드·실제 위젯 테스트·운영 통계·대화 기록.
- 소유자 전용 생성/삭제/고객사 이동/키/외부 연동/결제는 고객사 관리자에게 제공하지 않는다.
- API마다 인증된 사용자와 URL customer/bot의 관계를 검사한다. knowledge 항목 ID와 폴더 ID도 동일 bot_id 조건을 사용한다.
- 임베딩/파일 추출 같은 외부 작업은 저장 전에 수행하고, 저장 트랜잭션에서 customer→bot 잠금·현재 멤버십을 재확인한다. 권한 회수나 소속 변경이 끼어들면 저장하지 않는다.
- customer/bot 응답은 허용 필드만 선택한다. 공개 설치 토큰은 설치 권한이 있는 관리자에게만 노출한다.

## 리뷰 중 보완

- 기존 에이전시 Q&A 수정/삭제가 항목 bot_id를 누락한 것을 수정. 타 고객사 Q&A ID 변조 HTTP 검사 추가.
- 기존 문서/Q&A 생성 시 폴더의 bot_id 검사와 문서 임베딩의 tenant 키 사용 추가.
- 고객사 간 봇 이동은 기존 소속/대상 고객사를 정렬 잠금 후 상태 재확인. 고객사 작업과 소속 이동이 경합해도 권한 범위를 유지한다.
- 텍스트 입력 요청의 스트림 상한은 기본 12KB를 유지하되 지식 편집만 220KB로 명시 확대. 파일은 전송 중 상한 및 파일별 5MB(로고 2MB)를 적용한다.
- 파일 추출은 기존 파서를 공유한다. 확장자 허용 목록, 본문 길이, Q&A 최대 100건과 필드 검증 후 임베딩. 파일 이름을 경로로 사용하지 않는다.
- URL 가져오기는 기존 SSRF 방어·변경 비교를 재사용하며 preview/apply·메타데이터 저장도 현재 권한을 재확인한다.
- URL 승인 후 문서 목록 갱신 콜백 추가. API 주소 변경을 WebSourceManager의 effect 의존성에 포함.

## 검증과 제한

- 전체 단위 124개, 고객사 DB 39개(모두 롤백), 실제 HTTP 31개 통과.
- HTTP는 관리자 설정·조회·통계·로그·URL 원본 조회, 일반 담당자 거부, 타 봇/Q&A 항목 변조 거부를 포함.
- 브라우저: 고객사 관리자 로그인→자기 봇 목록→설정/문서·URL/통계 화면 확인. 캡처 docs/verification/prd-execution/.
- 타입·빌드 통과. 변경 파일 린트 오류 없음(이미지 요소 경고는 최적화 권고).
- 실제 모델 키를 사용하는 임베딩·대화·URL 승인 전체 왕복과 실제 외부 채널은 환경 검증 대기다. DB 서비스는 합성 벡터로 CRUD·격리/감사를 검사했다.
- 실제 위젯 테스트는 기존 방식으로 테스트 대화가 저장될 수 있음을 화면에 안내한다. 공유 데모의 별도 격리는 다음 데모 PR 범위다.
- 이 PR은 공통 Google 로그인·전체 이관·전체 L01~L18 완료가 아니다.

독립 Codex 리뷰 및 CI 결과는 PR에서 추가 확인한다. 작성자 리뷰만으로 독립 리뷰 통과라고 표시하지 않는다.
