# PRD 실행 02 — 작성자 코드 리뷰

고객사 정보 수정·비활성화·감사·구성원 요청 제한 및 봇 생성 경합.

- 고객사 행 잠금 후 현재 활성 사용자/소유자 또는 관리자 권한 재확인. 비활성 고객사는 소유자만 재활성 가능.
- 상담 담당자·다른 고객사 관리자에게 수정 불가. 고객사 관리자는 운영 상태 변경 불가.
- 비활성화 시 봇·활성 멤버·미종료 상담 확인하고 pending 초대를 무효화. 데이터 삭제는 제공하지 않음.
- 리뷰에서 고객사 검사와 봇 삽입 사이 경합 발견. 봇 생성 트랜잭션에서 tenant 잠금·현재 플랜/구독/개수 재검사와 customer 잠금·활성 재검사를 추가.
- 생성·수정·봇 이동·초대 취소 성공 감사 기록. 구성원/초대 권한 거부는 현재 해당 고객사 읽기 권한이 있을 때만 payload 없이 감사 기록. 타 고객사 존재 유출 안 함.
- 멤버 변경 30/분, 초대 10/분, 고객사 정보 변경 30/분 제한.
- UI 저장 실패는 입력 유지. 실제 고객사 이름과 활성 상태만 노출, 비밀값 미포함.

검증: 격리 DB 29개(7개 추가) 통과 및 전체 롤백, 실제 로그인 HTTP 29개(정보 수정 범위·비활성/재활성·감사·동시 봇 생성 한도 추가) 통과. 변경 TS/TSX 린트·타입·빌드 통과.

독립 자동 리뷰는 PR에서 별도 요청한다. 작성자 리뷰를 독립 리뷰로 표시하지 않는다.
