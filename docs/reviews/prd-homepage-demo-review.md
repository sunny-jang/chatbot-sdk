# 고객 홈페이지 공유 데모 검수

## 범위

에이전시 소유자가 등록 고객사·챗봇과 공개 홈페이지 주소로 만료되는 체험 링크를 발급한다. 실제 홈페이지를 iframe 배경으로 표시하고 기존 위젯을 데모 전용 API에 연결한다. iframe을 차단하는 사이트는 사용자가 대체 화면 버튼을 누르면 생성된 표지로 전환한다. 교차 출처 차단 여부를 자동 감지했다고 주장하지 않는다.

토큰 원문은 생성 응답에서만 표시하고 DB에는 해시만 저장한다. 링크 해제·만료, 소유자 권한 회수·고객사 비활성화·봇 소속 변경을 서버에서 다시 검사한다. 데이터 조회·저장·AI 문맥은 데모와 세션별로 격리하며 운영 chat_sessions/chat_logs/접수/알림/월 사용량에 기록하지 않는다. 데모 폼은 연락처 원문 대신 제출 해시와 DEMO 영수증만 저장한다.

등록된 Q&A는 실제 답변을 반환한다. 자유 질문은 해당 봇 지식과 데모 자체 대화만 모델에 전달한다. 브라우저가 보낸 과거 대화를 신뢰하지 않는다. AI는 등록된 고객사 키를 사용한다. 데모별 100회, 테넌트별 하루 AI 1,000회와 시간 제한을 적용한다. 실제 모델 호출 비용은 발생할 수 있음을 생성 화면에 알린다. 만료·해제 후 24시간이 지난 데이터는 기존 정리 작업으로 삭제한다.

## 검증 근거

2026-10-22 격리 QA DB 및 localhost:3012에서 검증:

- DB 10건 전체 통과·롤백: 토큰 해시/조회, 멱등 및 내용 충돌, 한도, 운영 데이터 분리, 해제, 만료, 소유자 권한 회수.
- HTTP 8건 전체 통과: 관리 권한과 내부 주소 거부, 생성/공개 화면, 위젯 안전 설정, Q&A 응답/멱등/다른 세션 격리, 다른 데모 격리, 신청 중복·실접수/작업 미생성·연락처 미저장, 실제 시간 만료 410, 링크 해제 410.
- 브라우저: 합성 QA 소유자로 생성 → 공개 링크 → 홈페이지 iframe → 대체 화면 전환 → 실제 위젯 열기 확인. 캡처는 docs/verification/prd-execution/demo-*.png.
- 프로덕션 빌드 통과. 기존 고객사 관리 리뷰 수정도 포함한 상태에서 검사.

결과 파일: docs/qa/results/prd-homepage-demo-http.json.

## 미검증·제한

실제 고객사 API 키를 사용하는 AI 전체 왕복은 아직 미실행이다. 합성 Q&A 응답과 DB용 벡터로 격리 동작을 검증했으며 실제 AI 품질·비용·응답 시간을 통과로 표시하지 않는다. 외부 홈페이지 내부 스크롤·클릭 분석은 교차 출처 iframe에서 제공할 수 없으므로 실제 위젯 설치 후 기능임을 화면에 안내한다. 운영 DB 마이그레이션과 운영 배포는 아직 하지 않았다.

## 독립 리뷰 후 보완

선행 고객사 Q&A 재가져오기 중복·시트 폴더 수정(b5d3991)을 통합했다. 데모 일일 AI 예산은 model_started_at 기준으로 분리했다. 정적 Q&A, 정확히 일치하는 질문, 모델 요청 전 검증 실패는 AI 예산을 소모하지 않는다. 임베딩 또는 답변 모델 요청을 시작한 턴은 같은 턴에서 한 번만 예약하며, 요청 후 실패도 비용 보호를 위해 예약을 유지한다. 테넌트 잠금으로 동시 요청 한도를 직렬화한다. 회귀 DB 검사 12건 통과(롤백).

### 독립 리뷰 2차 (2026-10-23, Claude code-review — Codex 사용량 한도로 대체)

Codex 리뷰 봇이 사용량 한도 초과로 `failed`를 돌려줘 별도 리뷰 에이전트로 7건을 받았다.

반영 5건:

- 정확히 일치하는 질문은 최근 100건이 아니라 봇 전체에서 SQL로 찾고(공백 제거·소문자), 검색 후보 창은 500건으로 넓혔다. 오래된 Q&A가 데모에서 "모른다"로 보이지 않는다.
- 답변을 만들지 못한 턴은 `failDemoTurn`으로 방문자 턴 수를 돌려주고, 같은 요청 키로 재시도하면 실패한 행을 다시 pending으로 돌려 처리한다. AI 비용 예약(`model_started_at`)은 비용 보호를 위해 그대로 둔다. DB 검사 1건 추가.
- `demoSiteUrl`이 AUTH_URL·CUSTOMER_PORTAL_ORIGIN 호스트를 거부해 데모 페이지가 에이전시 앱이나 desk 포털을 iframe으로 띄울 수 없다. 단위 검사 추가.
- `lockPublicDemo`: 토큰 해시로 id·tenant만 읽어 잠근 뒤 검증 조회를 한 번만 수행한다(이전에는 5개 테이블 조인을 잠금 전후 두 번).
- 데모 화면의 iframe `onError`는 X-Frame-Options/CSP 차단에서 발생하지 않는 죽은 코드라 제거하고, 로드 후에도 "차단 시 비어 보임 → 대체 화면" 안내를 유지한다.

미반영 2건(사유 기록):

- 임베딩 JSON을 턴마다 다시 파싱하는 비용: 임베딩 열이 TEXT라 SQL 유사도 계산이 불가능하고 데모 전용 경로(세션당 최대 100턴)라 범위를 500건으로 제한하는 선에서 둔다. pgvector 도입 시 함께 정리한다.
- 위젯이 운영 `/api/chat/[botId]`에도 `requestId`를 보내지만 운영 라우트는 아직 읽지 않는다. 운영 멱등 처리는 별도 범위(상담 전송 멱등은 이미 idempotencyKey로 처리)이며 데모 어댑터만 사용한다고 여기에 기록한다.
