📚 Q&A 봇 Q&A Bot

관리자가 미리 등록한 Q&A 페어를 기반으로 응답합니다. 사용자의 질문을 OpenAI 임베딩으로 벡터화한 뒤 코사인 유사도로 가장 가까운 답변을 찾습니다.

동작 방식

사용자 질문
→
임베딩 생성
text-embedding-3-small
→
코사인 유사도
임계값 0.75
→
답변 반환
💡
매칭 임계값 유사도가 0.75 미만이면 "해당 질문에 대한 답변을 찾지 못했습니다."를 반환합니다. lib/embeddings.ts의 threshold 값으로 조정 가능합니다.

Q&A 등록 방법

추가 시 질문을 자동으로 임베딩해 저장합니다 (OpenAI 호출 발생)
3
수정/삭제도 가능
질문 수정 시 임베딩이 자동으로 재생성됩니다
✨ AI 봇 AI Bot

OpenAI Chat Completion API를 사용해 자유롭게 대화합니다. 시스템 프롬프트로 봇의 역할과 말투를 정의할 수 있습니다.

시스템 프롬프트 예시

시스템 프롬프트 예시 
당신은 [회사명]의 친절한 고객지원 상담원입니다.
- 항상 공손하고 간결하게 답변해주세요.
- 모르는 내용은 솔직하게 모른다고 말하세요.
- 제품 관련 질문에 집중하고, 관계없는 주제는 정중히 거절하세요.
- 한국어로만 응답하세요.

🌐 위젯 임베드

웹사이트의 </body> 태그 바로 위에 아래 코드를 붙여넣으세요.

기본 임베드 
<script src="https://your-server.com/chatbot-widget.js"
        data-bot-id="여기에-봇-ID"
        data-endpoint="https://your-server.com"></script>
⚠️
CORS 설정 필요 위젯이 다른 도메인에서 로드될 경우 Next.js 서버에서 CORS를 허용해야 합니다. 개발 환경에서는 같은 origin이면 문제없습니다.

실제 사용 예시

index.html 
<!DOCTYPE html>
<html lang="ko">
<head>
  <title>내 웹사이트</title>
</head>
<body>

  <!-- 웹사이트 콘텐츠 -->
  <h1>환영합니다</h1>

  <!-- 챗봇 위젯 (body 끝 바로 위) -->
  <script src="https://your-server.com/chatbot-widget.js"
          data-bot-id="abc-123"
          data-endpoint="https://your-server.com"></script>

</body>
</html>
⚙️ 설정 옵션

script 태그의 data-* 속성으로 위젯을 설정합니다.

속성필수기본값설명
data-bot-id 필수 — 관리자 패널에서 생성한 봇의 ID
data-endpoint 필수 — 챗봇 서버 URL (슬래시 없이)
data-theme 선택 light 위젯 테마 (light / dark)
🔌 채팅 API

위젯이 내부적으로 사용하는 API입니다. 직접 호출해 커스텀 UI를 만들 수도 있습니다.

POST /api/chat/:botId

요청 (Request) 
{
  "message": "배송은 얼마나 걸리나요?",
  "history": [              // AI 봇에서만 사용, 선택사항
    { "role": "user", "content": "안녕하세요" },
    { "role": "assistant", "content": "안녕하세요!" }
  ]
}
응답 (Response) 
{
  "reply": "주문 후 평균 2~3 영업일 내에 배송됩니다."
}
💡
커스텀 UI 연동 이 API를 React, Vue 등 어떤 프레임워크에서도 직접 호출해 자체 채팅 UI를 만들 수 있습니다.
🐘 그누보드에 설치하기

그누보드는 PHP 기반이지만 위젯은 순수 JS이므로 HTML에 script 태그만 추가하면 됩니다. 방법은 두 가지입니다.

💡
구조 이해 챗봇 서버(Next.js)는 별도로 운영되고, 그누보드 사이트는 위젯 JS만 불러옵니다. 그누보드 서버에는 아무것도 설치하지 않아도 됩니다.

응답 생성

방법 1 — tail.php 수정 (전체 페이지에 적용) 권장

그누보드는 모든 페이지 하단에서 tail.php를 공통으로 불러옵니다. 여기에 추가하면 사이트 전체에 챗봇이 붙습니다.

1
파일 열기
그누보드 루트의 tail.php 파일을 FTP나 파일 관리자로 엽니다.
2
스크립트 추가
</body> 태그 바로 위에 아래 코드를 붙여넣습니다.
3
저장 후 확인
그누보드 사이트의 아무 페이지나 열어보면 우측 하단에 챗봇 버튼이 나타납니다.
tail.php — </body> 바로 위에 추가 
<?php /* tail.php 파일 끝 부분 */ ?>

<!-- 챗봇 위젯 시작 -->
<script src="https://your-chatbot-server.com/chatbot-widget.js"
        data-bot-id="여기에-봇-ID"
        data-endpoint="https://your-chatbot-server.com"></script>
<!-- 챗봇 위젯 끝 -->

</body>
</html>
⚠️
tail.php 파일 위치 그누보드 버전에 따라 위치가 다를 수 있습니다. 보통 /tail.php(루트) 또는 스킨 폴더 안에 있습니다. 그누보드5는 루트의 tail.php가 공통 파일입니다.

방법 2 — 스킨 파일 수정 (특정 페이지만 적용)

특정 게시판이나 페이지에만 챗봇을 넣고 싶다면 해당 스킨의 skin.php 또는 list.skin.php 등을 직접 수정합니다.

적용 범위수정할 파일
사이트 전체 /tail.php
특정 게시판만 /skin/board/스킨명/list.skin.php 등
메인 페이지만 /skin/main/스킨명/index.skin.php
회원 관련 페이지만 /skin/member/스킨명/*.skin.php

방법 3 — PHP 조건으로 특정 페이지에만 표시

tail.php에 PHP 조건을 추가해 원하는 페이지에만 챗봇을 띄울 수 있습니다.

tail.php — 조건부 표시 예시 
<?php
// 예시 1: 로그인한 회원에게만 표시
if (is_member()) { ?>
  <script src="https://your-chatbot-server.com/chatbot-widget.js"
          data-bot-id="봇-ID"
          data-endpoint="https://your-chatbot-server.com"></script>
<?php } ?>

<?php
// 예시 2: 특정 게시판 페이지에서만 표시
if ($bo_table == 'notice') { ?>
  <script src="https://your-chatbot-server.com/chatbot-widget.js"
          data-bot-id="봇-ID"
          data-endpoint="https://your-chatbot-server.com"></script>
<?php } ?>

<?php
// 예시 3: 관리자에게는 숨기기
if (!is_admin()) { ?>
  <script src="https://your-chatbot-server.com/chatbot-widget.js"
          data-bot-id="봇-ID"
          data-endpoint="https://your-chatbot-server.com"></script>
<?php } ?>

자주 쓰는 그누보드 PHP 변수

변수 / 함수의미활용 예시
is_member() 로그인 여부 회원에게만 챗봇 표시
is_admin() 관리자 여부 관리자에겐 숨기기
$bo_table 현재 게시판 테이블명 특정 게시판에서만 표시
$_SERVER['REQUEST_URI'] 현재 페이지 URL 특정 URL 패턴 매칭
$member['mb_id'] 로그인한 회원 ID 회원별 맞춤 봇 ID 지정
💡
그누보드 관리자 페이지에서도 설정 가능 그누보드 관리자 → 환경설정 → 기본환경설정 → "공통 하단 스크립트" 항목에 script 태그를 붙여넣으면 파일을 직접 수정하지 않아도 됩니다. (버전마다 위치가 다를 수 있음)
🔑 환경변수

.env.local 파일을 프로젝트 루트에 생성합니다.

.env.local 
# OpenAI API 키 (필수)
OPENAI_API_KEY=sk-proj-...

# 서버 URL (임베드 코드 생성에 사용)
NEXT_PUBLIC_BASE_URL=http://localhost:3000
⚠️
보안 주의 OPENAI_API_KEY는 절대 클라이언트에 노출되면 안 됩니다. NEXT_PUBLIC_ 접두사를 붙이지 마세요. 모든 OpenAI 호출은 서버(API Routes)에서만 발생합니다.
